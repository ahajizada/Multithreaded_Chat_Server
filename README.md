# Multithreaded Chat Server

## Overview
This is a simple multithreaded chat server built in C++. It allows multiple clients to connect and exchange messages in real-time.

## Features
- Handles multiple clients using threads.
- Synchronizes access to shared resources using mutexes.
- Simple client interface for sending and receiving messages.

## How to Build
1. Clone the repository:
   - git clone https://github.com/ahajizada/multithreaded_chat_server.git
   - cd multithreaded_chat_server
2. Start the server:
   - ./server
3. Start multiple clients:
   - ./client
